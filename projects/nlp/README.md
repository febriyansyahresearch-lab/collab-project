# NLP — Text Classification

**Domain:** Natural Language Processing  
**Models:** Naive Bayes, Logistic Regression, SVM  

## Methodology

1. **Data**: Synthetic texts across 3 topics (tech, sports, finance)
2. **Vectorization**: TF-IDF with 1000 max features
3. **Models**: Compare 3 classifiers
4. **Evaluation**: Accuracy, precision/recall per class

## Usage

```bash
python -m projects.nlp.src.train
```
